 Assignment 02 — CampusWheels Vehicle-Rental Desk

**Course:** 192-201 Advanced Computer Programming with Generative AI  
**University:** Siam University — Faculty of Information Technology (International)

 Description

This project models a simple campus vehicle-rental desk using Python
object-oriented programming.

The program contains:

- `Vehicle`
- `Renter`
- `ElectricCar`
- `Motorbike`

The project demonstrates:

- Classes and objects
- Encapsulation
- Properties and validation
- Inheritance
- Polymorphism

 Files

 rental.py
Contains all classes used in the vehicle-rental system.

 main.py
Demonstrates how the classes work, including renting, returning,
validation, inheritance, and polymorphism.

 How to Run

Open a terminal in the `Assignment_02` folder and run:

```bash
python main.py
